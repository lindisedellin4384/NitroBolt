## 🛠️ How to Use Nitro Pro  

### 1️⃣ **Creating & Editing PDFs**  
- Open Nitro Pro and select **"Create PDF"** to import files (Word, Excel, images, etc.).  
- Use the **Edit Tool** to tweak text, fonts, and images.  
- Rearrange pages with drag-and-drop simplicity.  

### 2️⃣ **Signing & Securing Documents**  
- Click **"Sign"** to add digital or handwritten signatures.  
- Apply passwords via **File > Protect > Encrypt**.  

### 3️⃣ **Converting & Sharing**  
- Export PDFs to Word, Excel, or PowerPoint with **"Convert"**.  
- Share via email or cloud storage directly from Nitro Pro.
